# Packtrix logo

The mark is a cube of packages with its front corner taken out: the part of the repositories that Packtrix resolves and carries across the air gap.

## Files

| File | Use |
|---|---|
| `packtrix-logo.svg` | The logo on light backgrounds |
| `packtrix-logo-dark.svg` | The logo on dark backgrounds |
| `packtrix-mark.svg`, `packtrix-mark-dark.svg` | The mark alone, at 48 px and larger |
| `packtrix-mark-small.svg`, `packtrix-mark-small-dark.svg` | The mark alone, up to 32 px: solid faces stay sharp at small sizes |
| `favicon.svg`, `favicon.ico`, `favicon-32.png`, `apple-touch-icon.png` | Website icons. `favicon.svg` follows the browser's light or dark mode. |
| `avatar.png` | GitHub organization avatar (512×512) |
| `social-preview.png` | Repository social preview (1280×640) |

## Colors

| Name | Hex | Use |
|---|---|---|
| Ink | `#0F1B2D` | Text on light backgrounds, dark backgrounds |
| Paper | `#F4F6F8` | Light backgrounds, text on dark backgrounds |
| Signal orange | `#F26B1D` | The accent. The notch uses `#F69761`, `#F26B1D` and `#BD5317` for its three faces. |
| Cube on light | `#3B4B63`, `#24324A`, `#142033` | Top, left and right faces |
| Cube on dark | `#E2E8F0`, `#B6C2D2`, `#8A99AD` | Top, left and right faces |

## Wordmark

`packtrix`, lowercase, in [Space Grotesk](https://github.com/floriankarsten/space-grotesk) SemiBold with −3% letter spacing, converted to outlines. Space Grotesk is licensed under the SIL Open Font License 1.1.

## Changing the logo

Every file here is generated by [`hack/logo/build.py`](../../../hack/logo/build.py); its header lists what it needs. Change the script, not the files.
